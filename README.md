## 🎯 1. Executive Summary & Problem Statement

In India's vibrant manufacturing and textile hubs (such as **Tiruppur, Surat, Coimbatore, and Ludhiana**), job-work MSMEs complete their manufacturing work on Day 1, but routinely face **60 to 90-day payment delays** from large buyers. 

During this waiting period, MSMEs struggle to cover essential daily expenses:
- Worker wages & payroll
- Raw material yarn procurement
- Factory electricity & machinery maintenance
- Operational working capital

**NOOL CREDIT** bridges this financing gap with an institutional, explainable digital workflow:
$$\text{Upload Invoice} \longrightarrow \text{GST Verify} \longrightarrow \text{Risk Engine (0-100)} \longrightarrow \text{Bundle Pool} \longrightarrow \text{Lender Review} \longrightarrow \text{Instant Disbursement}$$

## 🌟 2. Key Highlights & Requirements Delivered

### 🌐 Multi-Language System
- Full real-time switching between **English**, **தமிழ் (Tamil)**, and **हिंदी (Hindi)** with zero full-page reload and persistent `localStorage` preference.
- All navigation, buttons, forms, risk factors, KYC workflows, and error/success states fully translated.

### 🎨 Authentic FinTech Design System
- **Primary:** Professional Financial Blue (`#0F4C81`, `#054685`)
- **Success:** Emerald Green (`#059669`, `#10B981`) for Verified, Low Risk, Approved, Disbursement
- **Warning:** Amber / Orange (`#D97706`, `#F59E0B`) for Under Review, Pending
- **Error:** Rose / Red (`#DC2626`) for Rejected, Duplicate flags
- **Neutral:** Clean slates, light grays, and soft blue-gray borders.

### 🎙️ "NOOL VOICE" AI Voice Assistant
- Integrated sound-wave bars, speech recognition, and speech synthesis.
- Answers invoice financing queries with prototype safety disclaimers.

### 🛡️ NOOL Credit Readiness Score & Explainable Risk
- Animated radial score gauge ($0 \to 86 / 100$) with dynamic score breakdown:
  - *Business Profile:* 18 / 20
  - *Document Verification:* 18 / 20
  - *Invoice Quality:* 19 / 20
  - *Buyer Reliability:* 14 / 15
  - *Payment History:* 12 / 15
  - *Platform Activity:* 5 / 10
- Transparent positive factors and risk warnings.

### 🔒 Privacy UI & Masked Digital KYC Journey
- Visual journey tracker: $\text{Aadhaar} \to \text{PAN} \to \text{Bank} \to \text{Business} \to \text{Documents} \to \text{KYC Complete ✓}$
- Sensitive data masked by default: Aadhaar (`XXXX XXXX 4521`), PAN (`XXXXX1234X`), Bank (`XXXX XXXX 8892`).
- Global **Show / Hide Balance** toggle.

### 📦 Dynamic Invoice Pooling & Live Bundler
- Multi-select invoices to create diversified risk pools with live weighted score calculation ($₹2,60,000 \implies 82/100 \implies ₹2,08,000$ recommended capital at 80-85%).

### 🏦 3-Layer Institutional Anti-Fraud Architecture
- **Government GST Verification:** Connects to authorized **GST Suvidha Providers (GSPs)** to check invoice authenticity instantly.
- **E-Invoice Tamper Check:** Scans the cryptographic IRN QR code generated by the IRP portal.
- **Fake History Prevention:** Uses the **RBI Account Aggregator (AA) Framework** (via FIU architecture) to securely fetch and cross-match immutable bank statements, ensuring past buyer payments are 100% real.

### 🏦 Dual Portal Experience (MSME & Lender)
- Instant Demo Mode bar at top to switch effortlessly between MSME and Lender viewpoints.
- 1-click Lender decisioning with confirmation modals, rejection reason taxonomy, and disbursement status tracking.

## 🚀 5. Quick Start Instructions

### Prerequisites
- Node.js (v18+)
- MongoDB (Optional. Uses robust in-memory store if MongoDB is not running locally)

### Step 1: Run Backend (Express API)
```bash
cd server
npm install
npm run dev
```
Backend API starts at **http://localhost:5000**.
*(Note: It auto-falls back to an in-memory database if MongoDB is not available, so you can run the demo immediately with zero config!)*

### Step 2: Run Frontend (React/Vite)
```bash
cd frontend
npm install
npm run dev
```
Open **http://localhost:5173** in your browser.

## 📡 6. REST API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/auth/login` | JWT Authentication & role assignment |
| `POST` | `/api/auth/register` | Register new MSME / Lender |
| `GET` | `/api/invoices` | List MSME invoices |
| `POST` | `/api/invoices` | Upload & verify invoice with OCR extraction |
| `POST` | `/api/risk/calculate/{id}` | Run explainable risk assessment (0-100) |
| `GET` | `/api/pools` | List created invoice pools |
| `POST` | `/api/pools` | Bundle multiple invoices into a structured pool |
| `POST` | `/api/financing/request` | Submit pool for institutional financing |
| `GET` | `/api/financing/lender` | Lender queue of financing applications |
| `PUT` | `/api/financing/{id}/approve` | Lender 1-click approval & disbursement initiation |
| `PUT` | `/api/financing/{id}/reject` | Lender rejection with structured reason |

## ⏱️ 7. 2-Minute Hackathon Demo Script

1. **Landing Page:** Open `http://localhost:3000`. Show the hero floating cards, the Day 1/30/60/90 MSME cash flow problem timeline, and trigger **NOOL VOICE** ("How can I finance my invoice?").
2. **Language Switch:** Click the language dropdown and toggle to **தமிழ்** or **हिंदी** to show immediate UI translation.
3. **MSME Dashboard:** Navigate to `/dashboard`. Highlight the KPI cards, invoice value trend chart, and click **Upload Invoice**.
4. **Invoice Extraction:** Drop an invoice file to trigger simulated OCR scanning (Uploading $\to$ Extracting $\to$ Verifying $\to$ Analysing). Save and view verification score (96%).
5. **Check Eligibility & Score:** Go to `/eligibility` to showcase the animated **86 / 100** score ring and metric breakdown.
6. **Invoice Bundling:** Open `/pool`. Select 3 invoices ($₹2,60,000$) to see live weighted score (82) and recommended financing ($₹2,08,000$). Click **Submit Financing Request** (confetti triggers).
7. **Lender Approval:** Use the top **DEMO MODE** bar to switch to **Lender Portal**. Open the application review, review positive/risk factors, and click **Approve Financing**.
8. **Disbursement:** Switch back to MSME to verify **DISBURSEMENT INITIATED** status.
